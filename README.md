# ![GA Logo](https://ga-dash.s3.amazonaws.com/production/assets/logo-9f88ae6c9c3871690e33280fcf557f33.png) Spark/PySpark, Databricks, and Big Data

## Learning Objectives
By the end of this lesson, you should be able to:
- Describe Spark, Databricks, and what problems each solves for data scientists.
- Describe cluster computing, resiliency, parallelizability, and lazy evaluation in the context of model development.
- Create a compute cluster in Databricks.
- Create temporary and permanent datasets in Databricks by uploading a local files.
- Run SparkSQL commands in Databricks.
- Use Spark to conduct exploratory data analysis on large datasets.
- Use SparkML to fit, generate predictions from, and evaluate a machine learning model.

There is no starter code for today. We will spin up a blank Databricks notebook.

## Before Class...
You need to download our data and create a free Databricks account.

### Download our NYC Taxi Data
1. Head here: https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page
2. Click 2024 > October > Yellow Taxi Trip Records (PARQUET) to download a file locally.

### Create a *Free* Databricks Account
1. Go to https://www.databricks.com/try-databricks and fill out the information.
2. Beneath "How will you be using Databricks?" Click “Get started with Community Edition.”
3. Check your email and verify your account by clicking the URL after “Get started by visiting."
4. Once at community.cloud.databricks.com/login.html, type in your email to log in.
5. Check your email again. Enter the code that has been sent to you.
